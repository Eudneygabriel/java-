Fluxos de Dados

Em Java, o pacote java.io oferece uma abstração de fluxo de dados. Fluxos são responsáveis por ler e escrever dados de diversas fontes, como arquivos, memória e redes.

Os fluxos podem ser de dois tipos: fluxos de bytes e fluxos de caracteres. Fluxos de bytes são usados para manipular dados binários, enquanto fluxos de caracteres são usados para manipular dados textuais.

Fluxos de Entrada e Saída

Fluxos de entrada são responsáveis por ler dados, enquanto fluxos de saída escrevem dados. Os fluxos mais comuns são:

  • InputStream (entrada de dados em bytes)
  • OutputStream (saída de dados em bytes)
  • Reader (entrada de dados em caracteres)
  • Writer (saída de dados em caracteres)

Fluxos Encadeados

Você pode encadear fluxos para otimizar a leitura e a escrita de dados. Por exemplo, você pode usar BufferedReader para ler dados com mais eficiência. 

BufferedReader br = new BufferedReader(new FileReader("exemplo.txt"));

Leitura e Escrita de Arquivos

Trabalhar com arquivos é uma tarefa comum em Java. Para isso, utilizamos fluxos para ler e escrever dados. O pacote java.io contém várias classes úteis para esse propósito.

Leitura de Arquivos

Para ler dados de um arquivo, podemos usar o FileReader, que é ideal para ler caracteres. Para otimizar a leitura, usamos o BufferedReader. 

BufferedReader reader = new BufferedReader(new FileReader("arquivo.txt"));

Esse código cria um objeto BufferedReader que pode ler o conteúdo do arquivo de forma mais eficiente.

Escrita em Arquivos

Para escrever em arquivos, usamos o FileWriter ou o BufferedWriter, que oferece mais eficiência ao escrever grandes quantidades de dados. 

BufferedWriter writer = new BufferedWriter(new FileWriter("saida.txt"));

Fechando Fluxos

Fechar os fluxos após o uso é essencial para evitar vazamentos de recursos. Usamos o try-with-resources para garantir o fechamento automático dos fluxos. 

try (BufferedReader br = new BufferedReader(new FileReader("arquivo.txt"))) {
    // Lógica de leitura
} catch (IOException e) {
    e.printStackTrace();
}

Serialização de Objetos

A serialização é o processo de transformar um objeto em uma sequência de bytes. Isso é útil para salvar o estado de um objeto em disco ou enviá-lo por rede.

Em Java, um objeto precisa implementar a interface Serializable para ser serializado.

Exemplo de Serialização

Veja um exemplo básico de serialização:

import java.io.*;

public class ExemploSerializacao {
    public static void main(String[] args) throws IOException {
        Person p = new Person("João", 30);

        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("pessoa.ser"))) {
            oos.writeObject(p);
        }
    }
}

class Person implements Serializable {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

Deserialização

Para deserializar um objeto, usamos ObjectInputStream: 

try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("pessoa.ser"))) {
    Person p = (Person) ois.readObject();
    System.out.println(p.name + " - " + p.age);
} catch (IOException | ClassNotFoundException e) {
    e.printStackTrace();
}

Tratamento de Exceções

Exceções são eventos que interrompem o fluxo normal de um programa. Elas podem ser previstas ou imprevistas.

Existem dois tipos de exceções: verificadas e não verificadas.

Exceções Verificadas

Exceções verificadas, como IOException, devem ser tratadas explicitamente, ou então o compilador gera um erro.

Exceções Não Verificadas

Exceções não verificadas, como NullPointerException, não exigem tratamento obrigatório, mas devem ser tratadas para evitar falhas inesperadas.

Blocos try-catch

O bloco try-catch é usado para capturar e tratar exceções: 

try {
    int resultado = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Erro de divisão por zero!");
} finally {
    System.out.println("Bloco finally executado");
}

Banco de Dados

Java tem uma API chamada JDBC (Java Database Connectivity) para interagir com bancos de dados relacionais.

Para realizar operações como consultas e atualizações, usamos objetos como Connection, Statement e ResultSet.

Exemplo de Conexão JDBC

Conectar a um banco de dados MySQL:

import java.sql.*;

public class ExemploJDBC {
    public static void main(String[] args) throws SQLException {
        Connection conn = DriverManager.getConnection("jdbc:mysql://localhost:3306/meubanco", "usuario", "senha");
        Statement stmt = conn.createStatement();
        ResultSet rs = stmt.executeQuery("SELECT * FROM clientes");

        while (rs.next()) {
            System.out.println(rs.getString("nome"));
        }

        conn.close();
    }
}

Concorrência

A concorrência é importante em sistemas que necessitam de alto desempenho. O Java fornece suporte para criar e gerenciar threads e processos simultâneos.

A classe Thread é a base para a criação de threads em Java, e o pacote java.util.concurrent oferece classes avançadas para controle de threads.

Exemplo de Thread

class MinhaThread extends Thread {
    public void run() {
        System.out.println("Executando thread...");
    }
}

public class ExemploThread {
    public static void main(String[] args) {
        MinhaThread t = new MinhaThread();
        t.start();
    }
}

Desempenho e Escalabilidade

O desempenho é uma característica fundamental de qualquer sistema. No Java, é importante otimizar o código para reduzir o tempo de execução e o uso de recursos.

O conceito de escalabilidade se refere à capacidade de um sistema de lidar com um aumento na carga de trabalho, sem perder desempenho.

Melhorando o Desempenho

Algumas práticas incluem o uso de caches, a otimização de algoritmos e a utilização de múltiplas threads para processar dados em paralelo.
